# FOR KAMMO — September, somehow.

Clean rebuild of the interactive anniversary site.

## Structure
- index.html
- style.css
- script.js
- assets/photos/01.jpg ... 07.jpg

## GitHub Pages
Upload the contents of this folder to the repository root, then enable GitHub Pages from the `main` branch and `/root`.

The image paths are intentionally `./assets/photos/01.jpg` etc. so they work on GitHub Pages.

## Main effects
- 6,000-particle 3D heart bloom + heartbeat pulse
- 3D blooming lotus
- Three.js star field
- Interactive orbit gallery
- Lightbox + fairy dust
- 3D butterflies in lightbox
- Swipe, wheel, keyboard and button navigation

Navigation does not depend on Three.js loading, so a WebGL/CDN problem cannot prevent the first page from moving.
